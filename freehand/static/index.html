Remote Gateways

Connectors vs gateways: a connector is an account the agent acts with (e.g. your Slack shared app → post/read channels). A gateway is a channel that reaches you — where approval buttons and remote commands arrive (Telegram / Slack / WhatsApp bot tokens below). Different credentials, different jobs.
